# ApexMCP Community

This is the public community hub for [ApexMCP](https://apexmcp.ai) — the platform that connects AI agents to your data sources via the Model Context Protocol (MCP).

## What is ApexMCP?

ApexMCP lets you expose your databases, APIs, and SaaS tools as MCP-compatible endpoints that any AI agent (Claude, Cursor, Copilot, etc.) can use — with built-in auth, rate limiting, credential management, and audit logging.
